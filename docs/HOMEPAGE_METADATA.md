# Catalog metadata provenance

The 15 entries in `courses.json` remain in the manually curated default order. `gold-volatility` joins `unknown-unknowable` and `pozsar-money-view` under `投资与决策`; `us-data-center-buildout` retains `产业与基础设施`; `overcome-inner-resistance` uses `学习与成长`. Original tags and course routes remain intact. The homepage's two suggested routes are authored in `scripts/catalog.mjs` and link existing courses only.

`sourceAddedAt` and `sourceUpdatedAt` mean the earliest and latest commits touching `content/courses/<slug>/index.html` in this repository's history through each course's recorded source commit. They do **not** assert when an original source was published or researched. For each slug, the values came from `git log --format='%H %cI' -- content/courses/<slug>/index.html`: last output line for the first appearance, first output line for the latest source change. The paired `sourceAddedCommit` and `sourceUpdatedCommit` are unique seven-character commit abbreviations. Committer dates retain their recorded timezone; the browser compares them as instants. A missing or invalid date sorts last, with curated order as the tie-breaker. Dates are frozen metadata, not computed at runtime.

The title sort uses `zh-CN` collation and the same curated tie-breaker. Search includes only authored course title, subtitle, description, category and tags. It does not search lesson text or private course notes. Station counts are source metadata, not a duration or completion estimate.
