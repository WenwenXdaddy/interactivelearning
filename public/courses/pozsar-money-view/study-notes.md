# Pozsar 货币观：从资产负债表到全球储备

材料：Fzz，2026-05-23。核查：2026-09-17。

## 速查
- 准备金与基金存款：MMF通过银行结算；不能记为MMF自己的准备金。（站07第2步）
- ON RRP峰值：2022-12-30约2.55万亿美元；季末数与日均数分开。（站07第3步）
- 杠杆比率：一级资本 ÷ 总杠杆暴露；资产与负债不机械相加。（站05第1步）
- 流动性缓冲：LCR = HQLA ÷ 30天压力净流出；压力期可动用。（站06第1步）
- 五级传导：约束收紧→中介供给下降→基差扩散→被迫减仓→长端失序与政策回应。（站14第1步）
- 2019年回购压力：2019-09-17 SOFR 5.25%、EFFR 2.30%，口径不同。（站16第2步）
- 购金与份额：吨数流量、持有量及市值份额分别解释；COFER不含黄金。（站25第3步）
- 投资情境边界：条件、路径、替代解释与失效情形一起读。（站33第1步）
- 可证伪的利差：SOFR−IORB ≥ 5bp 是利差条件，不能写成水平连比。（站35第2步）

## 各站结论
- 站00 起点与地图：阅读路线先建立账户与约束，再检验危机与政策回应，最后讨论储备秩序和条件化投资情境；Fzz 的整合论述与 Pozsar 原作始终分开。
- 站01 货币观改变了什么问题：Fzz 把货币观理解为对结算、融资与中介约束的联合分析；总量相同不保证资金可达性相同。
- 站02 四层货币：先识别发行者与支持：这四层是 Fzz 组织材料的分类法；信用支持、抵押品与资产可及性需要分开辨认。
- 站03 Inside／Outside Money 的边界：Fzz 将交易对手信用问题延伸为资产可及性问题；同一个 Inside／Outside 标签不能跨口径直接套用。
- 站04 匹配账簿怎样连接现金与杠杆：匹配账簿通过融资中介赚取息差；利率风险较小，也仍占用资产负债表、结算与风险管理资源。
- 站05 SLR：低信用风险也会占用资本：SLR 可提高低风险中介业务的资本成本；是否实际约束某家银行，仍要看其缓冲与其他资本要求。
- 站06 LCR 与 G-SIB：缓冲与日历并不相同：Fzz 用流动性偏好与报告日激励解释资金分布；两种机制都需要机构适用范围与实际行为证据。
- 站07 ON RRP：看清联储负债的转换：ON RRP 存续期间把联储负债从准备金转换为逆回购；资金能在到期后重新选择投资，并非永久封存。
- 站08 影子银行需求从何而来：Fzz 把影子银行的扩展解释为现金安全需求与证券融资需求的匹配，而非一个单独机构的行为。
- 站09 保荐回购：净额化改变哪一层：保荐回购可以改善净额结算与资本效率，但不能把担保、清算和保证金责任理解为消失。
- 站10 地板体系与最后交易商：IORB、ON RRP 与 SRF 分别面对不同参与者和交易方向；工具存在不保证资金无摩擦传给所有需求者。
- 站11 准备金总量与分布为何不同：准备金变化既有联储负债构成的因素，也有银行分布和出借意愿的因素，二者不能相互替代。
- 站12 离岸美元：四层渠道与私人互换：离岸美元压力取决于融资成本和中介容量；Fzz 的四层图是分析安排，不是一条所有资金必经的串行路径。
- 站13 三种基差怎样读，怎样不能读：基差能反映中介稀缺性，但不能单独证明套利安全、危机必然发生或结构性转型完成。
- 站14 五级传导链：从约束到央行回应：五级链提供事件追踪顺序；它不是已估计的递推方程，也不保证所有冲击都走到第五级。
- 站15 非线性从哪三个环节产生：非线性来自约束与行为的相互作用；三个事后案例可以检验叙述是否相容，不能单独证明普适因果。
- 站16 2019：缴税与国债结算如何相遇：2019 年展示融资需求增加与准备金减少相遇的压力；监管约束是候选解释，不能据此认定唯一原因。
- 站17 2020：为什么国债也被抛售：高质量抵押品也会因现金需求被卖出；事件支持融资与价格联动，但各环节强度仍须分别验证。
- 站18 2022 LDI：抵押品损失如何自我放大：LDI 案例显示保证金与被迫卖出能相互放大；共同机制可比较，不能由此把危机起点都归为 SLR。
- 站19 ON RRP 下降：缓冲如何转移：ON RRP 的下降反映投资选择与联储负债构成变化；接近零后准备金对其他负债波动可能更敏感。
- 站20 RMP：政策目的与扩表方向要分开：准备金管理购买与刺激性 QE 可有不同目的，但两者都可能增加证券资产；“非 QE”不等于“不扩表”。
- 站21 SVB 与 BTFP：分清适用规则与风险：SVB 支持审视未保险存款、久期与流动性管理的联动，却不能直接验证该银行被 LCR 和 SLR 同时卡住。
- 站22 eSLR 与 SRF：两种放松，两种边界：资本标准调整影响可扩表空间，SRF 影响合格融资可得性；是否改善市场承接力仍需行为数据。
- 站23 国债供给与中介供给的口径：国债供给和融资需求增长可对中介施压；总债务、可交易证券、库存和资本不能直接相减比较。
- 站24 MMF 配置与清算改革如何改变结构：市场化回购增加可改善融资供给，也增加对中介和清算安排的依赖；资产安全性不能仅按交易对手名称排序。
- 站25 央行购金：数量、估值与因果：央行购金增长可以支持储备偏好变化的判断；市值份额变化还含金价影响，不能独自验证 BW III 因果链。
- 站26 人民币、平行支付与商品定价：替代支付安排可在局部可用，而无需建成完整替代体系；支付量增长也不直接等于储备锚转换。
- 站27 哪些是被验证的，哪些仍是解释：这六项是 Fzz 的研究结论清单；事实相容、相关性与框架独立预测成功必须分开。
- 站28 三项修正：汇率、商品需求与投资者：储备组成、汇率水平与私人投资需求可以分化；原文的三项修正要求保留不同主体和时间尺度。
- 站29 七个扩展变量：约束系统的边界：新增变量应改变可检验条件，而不是给原框架贴上更广泛的解释力；其净作用尚未确定。
- 站30 安全资产：供给数量与可及性：安全性包含偿付、市场流动性与持有者可及性；三者可能变化不同步。
- 站31 BW III：原作提出了什么：Pozsar 提出商品与外部货币地位上升的可能秩序；Fzz 的三期划分和后续证据需要逐项限定。
- 站32 BW III：四项修正与四项阶段判断：Fzz 最终主张方向、速度、形式与逆变量分别判断；这仍是一套可更新的情景解释。
- 站33 情境一、二：周期压力与结构约束：周期性缓解和结构性约束可以同时存在；作者的策略映射没有给出概率模型或交易成本后的收益证明。
- 站34 情境三、四：储备迁移与技术变化：储备和技术变化可影响长期需求，仍不足以确定短期价格、可交易收益或适合个人的仓位。
- 站35 五项假说怎样被证伪：H1—H5 是 Fzz 提出的研究假说，尚不等同于回测结论；可证伪性取决于冻结定义与判据。
- 站36 四个未解决问题与引用边界：四个问题分别涉及组合权重、网络均衡、法律债权与生产率量级；本文没有提供这些问题的定量解。
- 站37 速查与自测：使用这套框架的前提，是区分主体、日期、分母与机制；有方向的叙事仍需要可被反证的条件。
- 站38 原文全文：原文、Fzz 的整合判断和本页核查结果分别保留；引用时请回到具体段落与一手文件的日期及口径。
